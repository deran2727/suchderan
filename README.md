## 已实现

- 0–100 平滑加载动画；等待首页图片与视频首帧准备，超时可使用海报进入，避免无限卡在加载页。百分比是视觉加载进度，不是视频下载字节占比。
- 首页原视频静音循环播放；离开首页自动暂停。右上菜单可以暂停或恢复背景视频。
- 四区块锚点导航、当前区块状态、手机折叠菜单。
- 五类作品卡片、鼠标与键盘悬停/聚焦效果、点击封面放大；手机可横向滑动查看全部卡片。
- 作品页默认黑白并显示文字；鼠标指向或键盘聚焦时恢复彩色并隐藏卡片文字。
- 联系页使用纯黑网格背景；鼠标指向二维码时适当放大，点击仍可打开大图。
- 微信二维码放大，关闭按钮和 Esc 关闭；电话与邮箱使用 tel/mailto 链接。
- 响应式布局、键盘焦点、弹窗焦点管理、减少动态效果偏好。

## 当前边界

- 网站是纯前端静态作品集，没有后台、数据库、登录或支付功能。
- 五个作品分类均有独立详情入口，完整长图与视频通过站内查看器展示。
- 正文采用本机 Arial / Microsoft YaHei；大标题、Logo 和形象使用原始导出素材。未提供原字体文件，正文细部字形可能略有不同。
- 手机端无单独设计稿，依据桌面视觉完成适配。
- 二维码展示原始素材；tel/mailto 是否唤起应用取决于本机默认电话/邮件程序。验收未发送邮件或拨号。
